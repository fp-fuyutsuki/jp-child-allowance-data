# データ方針

## 基本方針

このリポジトリは、日本の児童手当制度に関する公開制度情報を扱います。

制度情報は、原則としてこども家庭庁、厚生労働省、法令・通知、自治体等の公開情報に基づきます。主要データは国の公式情報を優先します。

## スコープ

本リポジトリで扱うデータは、児童手当制度の金額、年齢区分、子の順序区分、支給月、制度改正履歴、出典メタデータです。

## 年齢表現について

児童手当制度では「15歳到達後の最初の年度末」「18歳到達後の最初の年度末」など、年度末基準の表現が使われます。本リポジトリの v0.1.0 では、軽量な参照用途を優先し、`age_min` / `age_max` による単純な年齢区分で表現します。厳密な年度末判定が必要な場合は、利用側で補正してください。

## 支給日について

本リポジトリでは、支給月のみを提供します。具体的な支給日は自治体等により異なるため扱いません。

## 出典メタデータの確認

出典メタデータは、データの追跡可能性と保守性を保つために確認します。各出典には、可能な範囲で明確なタイトル、発行主体、URL、参照日を記載します。
